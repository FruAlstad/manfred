# MANFRED

A first-person Backrooms game. You are Manfred. You noclipped out of reality and landed in the yellow rooms.

Find the dark exit door. Something else is looking for you.

## Play

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5174`).

## Controls

- **WASD** move
- **Mouse** look
- **Shift** run
- **Esc** pause / release mouse

## Goal

Wander the buzzing fluorescent maze until you find the exit. If the tall thing in the dark catches you, Manfred stays in the wallpaper.
